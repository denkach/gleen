# DEN-22 five-language editorial audit

## Audit contract

On 2026-08-05, every string and function leaf in the ten typed message catalogs was read in each supported interface locale: Ukrainian (`uk`), Russian (`ru`), English (`en`), Spanish (`es`), and German (`de`). Each of the 50 locale/catalog pairs was checked for grammar, natural product register, terminology, interpolation order, plural forms, and invariant names. Function signatures, argument order, message shapes, generated-content language boundaries, prices, limits, features, and product behavior were not changed.

The canonical marketing plan names are `Free`, `Prism`, and `Spectrum`. They remain unchanged in every locale and every plan CTA. `Gleen`, `Notion`, `Obsidian`, `NotebookLM`, `Markdown`, and `Stripe` also remain invariant.
